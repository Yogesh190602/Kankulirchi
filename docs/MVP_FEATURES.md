# MVP Features

## Feature 1: Wallpaper Search

Providers:

- Wallhaven
- Pexels

Requirements:

- Search by keyword
- Infinite scrolling
- Preview images
- Download image

## Feature 2: Collections

Requirements:

- Create collection
- Rename collection
- Delete collection
- Add wallpaper to collection
- Remove wallpaper from collection

## Feature 3: Favorites

Requirements:

- Favorite wallpaper
- Remove favorite
- Favorites page

## Feature 4: Local Cache

Requirements:

- Download wallpapers locally
- Prevent duplicate downloads
- Cache metadata in SQLite

## Feature 5: Wallpaper Rotation

Requirements:

Intervals:

- 5 minutes
- 15 minutes
- 30 minutes
- 1 hour
- Daily

Modes:

- Sequential
- Random

## Feature 6: Wallpaper Apply

Requirements:

- Set wallpaper immediately
- Use GNOME gsettings

## Feature 7: History

Requirements:

- Track applied wallpapers
- Allow reapply
