# Kankulirchi

## Product Type

Desktop Personalization Engine for Linux.

## MVP Goal

Create a desktop application that allows users to:

1. Search wallpapers from online providers.
2. Save wallpapers into collections.
3. Automatically rotate wallpapers.
4. Change GNOME wallpapers programmatically.
5. Cache wallpapers locally.
6. Mark wallpapers as favorites.

## Initial Platform

- Arch Linux
- GNOME Desktop

## Out of Scope

- KDE Plasma
- Hyprland
- Pinterest
- AI recommendations
- Cloud Sync
- User accounts
- Theme synchronization
- Multi-monitor support

These features will be implemented in future releases.

## Success Criteria

A user can:

1. Search wallpapers.
2. Create a collection.
3. Select rotation interval.
4. Start rotation.
5. Have wallpapers automatically change in GNOME.
